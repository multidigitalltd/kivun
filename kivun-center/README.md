# Kivun Center — מרכז כיוון

תוסף וורדפרס לניהול **לוח משרות, קורסים וסדנאות** עבור מרכז כיוון, עם CRM מובנה,
אינטגרציית WooCommerce, תגיות דינמיות ל‑Elementor, אזור מעסיקים לניהול הגשות,
ושכבת נגישות (ת"י 5568 / WCAG 2.2 AA).

- **גרסה:** 1.5.1
- **דרישות:** WordPress 6.0+, PHP 8.0+ (נבדק עד 8.4)
- **טקסט דומיין:** `kivun` (RTL מלא)

## התקנה
1. **תוספים → הוסף תוסף → העלאת תוסף** → בחרו את קובץ ה‑ZIP → "התקן עכשיו" → הפעל.
2. לאחר ההפעלה נוצרים אוטומטית: סוגי התוכן, הטקסונומיות עם ערכי ברירת מחדל,
   טבלאות מסד הנתונים, ותפקיד "מעסיק". כדאי להיכנס פעם אחת ל‑**הגדרות → קישורים קבועים**
   וללחוץ "שמור" כדי לרענן את ה‑rewrite rules.

## סוגי תוכן (CPT) וטקסונומיות

| סוג תוכן | Slug | טקסונומיות |
|----------|------|------------|
| משרות    | `kivun_job`      | `kivun_job_scope` (היקף), `kivun_job_region` (אזור), `kivun_job_field` (תחום) |
| קורסים   | `kivun_course`   | `kivun_course_cat` (קטגוריה) |

נטענים אוטומטית בהפעלה ראשונה.

## שורטקודים

| שורטקוד | תיאור | פרמטרים (ברירת מחדל) |
|---------|-------|----------------------|
| `[kivun_jobs]` | לוח משרות עם סינון חי (AJAX) | `show_filters=yes` · `per_page=10` · `scope` · `region` · `field` |
| `[kivun_apply id=""]` | טופס הגשת מועמדות + קו"ח למשרה | `id` (ברירת מחדל: המשרה הנוכחית) |

| `[kivun_course_single id=""]` | עמוד קורס בודד | `id` |
| `[kivun_course_register id=""]` | טופס הרשמה לקורס (חינמי/בתשלום) | `id` |
| `[kivun_course_interest id=""]` | טופס "השאירו פרטים" (ליד) | `id` |
| `[kivun_workshops]` | ארכיון סדנאות | `category` · `per_page=12` · `columns=3` |
| `[kivun_workshop_single id=""]` | עמוד סדנה בודדת | `id` |
| `[kivun_spots_left id=""]` | מספר מקומות פנויים | `id` · `full_text=מלא` |
| `[kivun_my_applications]` | "ההגשות שלי" — אזור אישי למועמד | — |
| `[kivun_employer_register]` | טופס הרשמת מעסיק עצמאי | — |
| `[kivun_employer_dashboard]` | לוח המעסיק (משרות + הגשות) | — |
| `[kivun_accessibility_statement]` | הצהרת נגישות (ת"י 5568) | — |

> **שימוש ב‑Elementor:** ניתן להוסיף כל שורטקוד דרך וידג'ט "Shortcode". הנכסים
> (CSS/JS) נטענים אוטומטית כשהשורטקוד מוצג, גם בעמודים שנבנו ב‑Elementor.

## אזור המעסיקים וניהול הגשות

עמוד עם `[kivun_employer_dashboard]` מספק למעסיק שתי לשוניות:

**1. המשרות שלי** — פרסום משרה חדשה, צפייה בסטטוס (פורסם/טיוטה/ממתין), מונה הגשות
לכל משרה (עם תג "חדש"), ומחיקה.

**2. הגשות מועמדות** — ניהול כל ההגשות למשרות של אותו מעסיק:
- פרטי מועמד, מכתב מקדים והורדת קו"ח.
- שינוי **סטטוס** מובנה: חדש → נצפה → נוצר קשר → מוזמן לראיון → גויס / לא מתאים.
- **הערות פנימיות** (נשמרות אוטומטית).
- **סינון חי** לפי משרה, סטטוס וחיפוש חופשי.
- **ייצוא CSV** של ההגשות — מוגבל למשרות של אותו מעסיק בלבד.

> כל פעולה מאומתת בעלות (Nonce + בדיקת הרשאה + בדיקה שהמשרה שייכת למעסיק),
> כך שמעסיק לא יכול לגשת להגשות של משרות אחרות (מניעת IDOR).

## CRM בניהול

בכל עמוד עריכה של משרה/קורס/סדנה מופיע תיבת מטא ייעודית:
- **משרה** → "מועמדויות וקו"ח".
- **קורס** → "הרשמות ולידים".
- **סדנה** → "הרשמות לסדנה".

בכל טבלה ניתן לעדכן **סטטוס** ולהוסיף **הערות פנימיות** ישירות (AJAX), ולייצא CSV.
בנוסף קיימים עמודי ריכוז תחת התפריטים:
- **משרות → מועמדויות** (כל המועמדויות).
- **קורסים → הרשמות** (כל ההרשמות, הלידים וההרשמות לסדנאות).

הנתונים נשמרים בטבלאות `{prefix}_kivun_applications` ו‑`{prefix}_kivun_registrations`.

## ייצוא CSV
כפתור "ייצוא CSV" בכל תיבת CRM ובלוח המעסיק. הקובץ ב‑UTF‑8 עם BOM (תקין ל‑Excel).
מנהל מערכת מייצא הכול; מעסיק מייצא רק את ההגשות למשרותיו.

## תגיות דינמיות ל‑Elementor
בעת שימוש ב‑Elementor Pro מתווספת קבוצת תגיות **"Kivun Center"**:

- **קורס:** עלות, זמנים, משך, קהל יעד, מקסימום משתתפים, מקומות פנויים, חינמי/בתשלום.
- **משרה:** חברה, שכר, דרישות, תאריך אחרון להגשה.
- **סדנה:** תאריך, משך, מיקום, קהל יעד, מקסימום משתתפים.

## אינטגרציית WooCommerce
לקורס בתשלום: יוצרים מוצר WooCommerce (פשוט) עם המחיר, ומשייכים אותו בשדה
"מוצר WooCommerce" בתיבת פרטי הקורס. טופס ההרשמה מפנה אוטומטית ל‑Checkout.
קורס ללא מוצר משויך = חינמי (הרשמה ישירה).

## מיילים והתראות
- **הגשת מועמדות** → מייל למעסיק עם פרטי המועמד וקו"ח מצורפים.
- **הרשמה לקורס** → התראה לאדמין + אישור למשתמש.
- **ליד / סדנה** → התראה לאדמין.
- **הרשמת מעסיק** → מייל ברוכים הבאים.

כתובת היעד נקבעת לפי שדה "אימייל לקבלת הרשמות" של הפריט, אחרת מההגדרות הכלליות /
`admin_email`.

## שכבת הנגישות
נטענת בכל עמוד בצד הקדמי (לא בממשק הניהול ולא בעורך/תצוגה המקדימה של Elementor):

- **סרגל נגישות** עם 12 כלים: הגדלת/הקטנת טקסט, ניגודיות גבוהה, היפוך צבעים,
  גווני אפור, הדגשת קישורים/כותרות, קו תחתון לקישורים, גופן קריא, עצירת אנימציות,
  סרגל קריאה, סמן גדול, ואיפוס. ההעדפות נשמרות ב‑`localStorage`.
- **קישור "דלג לתוכן"** (skip link) ראשון בסדר ה‑Tab.
- פאנל נגיש מלא: `role="dialog"`, מלכודת פוקוס, סגירה ב‑ESC, החזרת פוקוס.
- **הצהרת נגישות** דרך `[kivun_accessibility_statement]`.

ניתן לכבות לגמרי או להתאים דרך הפילטרים (ראו למטה).

## ביצועים וטעינת נכסים
- נכסי הפרונט (CSS/JS) נטענים **רק** בעמודים שמציגים תוכן Kivun (CPT / ארכיון /
  טקסונומיה / שורטקוד), כולל זיהוי שורטקודים בתוך Elementor.
- **ללא jQuery** בצד הקדמי (Vanilla JS). Select2 בלבד נשאר בבורר המוצרים בניהול.
- נכסים **ממוזערים** (`.min`) נטענים בייצור; הגדרת `SCRIPT_DEBUG=true` טוענת את המקור.
- ה‑script נטען עם `defer`. שאילתות עם `no_found_rows` והשבתת מטמוני מטא/טרמינולוגיה
  היכן שאין צורך.

## Hooks & Filters למפתחים

### Actions
| Hook | מתי | פרמטרים |
|------|-----|---------|
| `kivun_after_application` | אחרי שמירת הגשת מועמדות | `$job_id`, `$data` |
| `kivun_application_status_changed` | מעסיק שינה סטטוס הגשה | `$app_id`, `$new_status`, `$old_status`, `$app` |

### Filters
| Filter | תיאור | ברירת מחדל |
|--------|-------|------------|
| `kivun_load_frontend_assets` | אילוץ/ביטול טעינת נכסי הפרונט | תלוי הקשר |
| `kivun_a11y_enabled` | הפעלה/כיבוי שכבת הנגישות | `true` (כבוי בניהול/עורך) |
| `kivun_a11y_skip_target` | מזהה היעד של "דלג לתוכן" | `content` |
| `kivun_a11y_org_name` | שם הארגון בהצהרת הנגישות | שם האתר |
| `kivun_a11y_contact_email` | מייל לפניות נגישות | `admin_email` |
| `kivun_a11y_contact_phone` | טלפון לפניות נגישות | ריק |
| `kivun_a11y_coordinator` | שם רכז/ת הנגישות | ריק |

דוגמה:
```php
add_filter( 'kivun_a11y_skip_target', fn() => 'main' );
add_filter( 'kivun_a11y_contact_phone', fn() => '03-1234567' );
```

## בנייה (Build) ותקני קוד
- **תקן קוד:** WordPress Coding Standards (PHPCS) — עובר 0 שגיאות / 0 אזהרות.
  תאימות PHP 8.0–8.4 (נבדק ב‑CI).
- **מיזעור נכסים:**
  ```bash
  cd kivun-center
  npm install      # terser + clean-css-cli (devDependencies)
  npm run build    # מייצר את קבצי ה-.min
  ```
- קבצי ה‑`.min` כלולים במאגר; אין צורך ב‑build כדי להריץ את התוסף.
